# AI Clinic — عيادتك الذكية 🏥

تطبيق موبايل احترافي للعيادات والمرضى، مبني بـ **React Native (Expo) + TypeScript**، عربي بالكامل مع دعم الاتجاه من اليمين لليسار (RTL)، ومزوّد بميزات ذكاء اصطناعي عبر **Claude API**.

## الميزات

### للأطباء / العيادات
| الميزة | الوصف |
|---|---|
| 📅 **إدارة الحجوزات** | عرض مواعيد اليوم والقادمة، تأكيد أو إلغاء، وبدء الكشف من الموعد مباشرة |
| 📁 **ملفات المرضى** | ملف كامل لكل مريض: البيانات، الحساسية، الأمراض المزمنة، سجل الزيارات والوصفات |
| ✨ **تلخيص الكشف (AI)** | تحويل ملاحظات الطبيب والعلامات الحيوية إلى ملخص طبي منظم بالعربية عبر Claude |
| 💊 **كتابة الوصفات (AI)** | إضافة أدوية يدوياً أو اقتراح مسودة وصفة بالذكاء الاصطناعي مع تحذيرات الحساسية |
| 🔔 **متابعة المرضى** | مهام متابعة لكل مريض (تُنشأ تلقائياً عند صرف وصفة) مع تنبيه للمتأخرة |

### للمرضى
| الميزة | الوصف |
|---|---|
| 🔍 **تصفح حسب التخصص** | باطنة، قلب، جلدية، أسنان، أطفال، عظام، عيون، أنف وأذن |
| 📅 **حجز المواعيد** | اختيار اليوم والساعة من المواعيد المتاحة فعلياً (بدون تعارض) |
| ⏰ **تذكير بالمواعيد** | إشعارات تلقائية قبل الموعد بـ 24 ساعة وقبله بساعة |
| 💊 **وصفاتي** | كل الوصفات بجرعاتها وتعليمات الطبيب |

## التشغيل

```bash
npm install
npm start          # ثم امسح QR بتطبيق Expo Go
# أو
npm run android
npm run ios
```

> **ملاحظة RTL:** يُفعَّل الاتجاه العربي الكامل بعد أول إعادة تشغيل للتطبيق.

## تفعيل الذكاء الاصطناعي (Claude)

لأسباب أمنية، **مفتاح Anthropic API لا يوضع داخل التطبيق أبداً** — أي مفتاح داخل حزمة التطبيق يمكن استخراجه. بدلاً من ذلك يتصل التطبيق بخادم وسيط بسيط موجود في مجلد [`server/`](server/):

```bash
cd server
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

ثم شغّل التطبيق مع رابط الخادم:

```bash
EXPO_PUBLIC_AI_API_URL=http://<عنوان-الخادم>:3000 npm start
```

- الخادم يستخدم موديل `claude-opus-4-8` مع Adaptive Thinking للتلخيص، و **Structured Outputs** لاقتراح الوصفات بصيغة JSON مضمونة.
- بدون ضبط `EXPO_PUBLIC_AI_API_URL` يعمل التطبيق بوضع تجريبي محلي يولّد ملخصات مبدئية بدون شبكة.

## البنية

```
src/
├── theme.ts                  # نظام التصميم (ألوان، مسافات، خطوط)
├── types.ts                  # نماذج البيانات
├── data/seed.ts              # بيانات تجريبية (تخصصات، عيادات، مرضى)
├── store/useStore.ts         # الحالة العامة (Zustand + AsyncStorage)
├── services/
│   ├── ai.ts                 # خدمة Claude (عبر الخادم الوسيط + وضع محلي)
│   └── notifications.ts      # تذكيرات المواعيد (expo-notifications)
├── components/ui.tsx         # مكونات واجهة مشتركة
├── navigation/               # تنقل حسب الدور (طبيب / مريض)
└── screens/
    ├── RoleSelectScreen.tsx  # اختيار الدور
    ├── doctor/               # لوحة الطبيب، المواعيد، المرضى، الكشف، الوصفات، المتابعة
    └── patient/              # الرئيسية، تفاصيل العيادة، الحجز، مواعيدي، وصفاتي

server/                       # خادم وسيط لـ Claude API (يحمل المفتاح بأمان)
```

## ملاحظات مهمة

- **البيانات محلية:** هذه نسخة تجريبية تحفظ البيانات على الجهاز عبر AsyncStorage. للإنتاج، اربطها بقاعدة بيانات سحابية (Supabase / Firebase) مع مصادقة حقيقية.
- **إخلاء مسؤولية طبية:** مخرجات الذكاء الاصطناعي (الملخصات واقتراحات الوصفات) مسودات مساعدة فقط — القرار الطبي والدوائي النهائي مسؤولية الطبيب المرخّص.
- **الإشعارات:** تتطلب جهازاً حقيقياً (لا تعمل التذكيرات على المحاكي بشكل كامل).
